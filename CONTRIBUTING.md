# Contributing

Run `npm run check` before proposing changes. Keep contributions focused and explain behavior, validation and limits.

Use original code and synthetic fixtures for tests. Do not submit secrets, personal paths, private chat exports, copied article text, game screenshots, extracted artwork, browser profiles, credentials or full scraped catalogues. Any third-party contribution needs a documented compatible license and the required notices; see RIGHTS.md.

Do not convert unknown values to zero, combine listed-luck percentages into unsupported odds, or mark historical/demo data as current gameplay evidence. Keep the tool-use guides independent from game-specific acquisition claims.
